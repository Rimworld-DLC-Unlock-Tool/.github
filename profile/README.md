# RimWorld DLC Unlocker Tool

A lightweight and universal **RimWorld DLC unlocker tool**, designed to automatically detect, manage, and activate available DLCs. Built to work with both **modded and unmodded versions of RimWorld**, providing a simple and straightforward setup process both on unmodded and modded versions of the game.

## ⚡ Installation & Setup Guide

### 1. Download Linua Updater

Download the latest available version from the repository's Releases page.

### 2. Extract the Files

Extract the downloaded archive into a dedicated folder. The application is designed to be portable.

### 3. Launch the Application

Run the executable and follow the instructions displayed on screen.

### 4. Select RimWorld

Choose your existing RimWorld installation directory.

### 5. Detect and Manage DLCs

Allow the application to scan your installation and identify available expansions.

### 6. Launch the Game

Start RimWorld through Steam and verify that your installed DLCs are available.

## 🔧 Troubleshooting

| Issue | Possible Solution |
|---|---|
| DLCs not showing in-game | Restart Steam and check your installed DLCs. |
| Game crashes on launch | Check mod compatibility and verify the game files through Steam. |
| Missing DLL errors | Verify application dependencies and reinstall the required runtime. |
| DLC detection not working | Make sure the correct RimWorld installation directory is selected. |
| Mods causing issues | Disable recently installed mods and test the game again. |
| DLCs still unavailable | Check your Steam DLC ownership, installation status, and game version. |
